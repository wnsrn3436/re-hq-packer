# HQ 포맷

천년의신화, 임진록2, 임진록2+ 는 게임 데이터를 `Data.hq` 와 `Data` 한 쌍으로 묶어 둔다. `Data.hq` 가 헤더, `Data` 가 본체이고 두 파일 모두 같은 방식으로 암호화되어 있다.

## 암호화

바이트마다 0x10 비트를 뒤집는다. 비트가 켜져 있으면 16 을 빼고 꺼져 있으면 16 을 더하는 것과 같다. 한 번 더 적용하면 원래대로 돌아온다.

```
암호화된 바이트 = 원래 바이트 XOR 0x10
```

## 헤더 (Data.hq)

변환을 풀면 값이 전부 10진수 문자열인 한 줄짜리 텍스트가 나온다.

```
총라인수 : [파일 개수]->이름<TAB>[크기]<TAB>[오프셋]->이름<TAB>[크기]<TAB>[오프셋]->
```

| 부분 | 내용 |
|---|---|
| `총라인수 : [N]` | 파일 개수 |
| 이름 | 본체 안 파일의 이름. 하위 폴더가 있으면 `폴더\이름` 꼴 |
| `[크기]` | 파일 크기. 바이트 단위 |
| `[오프셋]` | 본체 안에서 그 파일이 시작하는 위치. 첫 파일은 0 |

항목 사이의 `->` 는 암호화된 파일에서 `0D 0A` 두 바이트다. 이 두 바이트에 변환을 걸면 `1D 1A` 가 되어 문자열로 다루기 어려우므로 HQ Packer 는 이 자리를 `->` 로 바꿔 읽고 묶을 때 되돌린다.

## 본체 (Data)

헤더 순서대로 파일 내용을 그대로 이어 붙인 것이다. 정렬이나 빈자리 없이 앞 파일들의 크기 합이 다음 파일의 오프셋이 된다. 전체에 같은 변환이 걸려 있다.

## 푸는 순서

1. 두 파일에 변환을 걸어 되돌린다.
2. 헤더를 `->` 로 갈라 항목마다 이름, 크기, 오프셋을 얻는다.
3. 본체에서 오프셋부터 크기만큼 잘라 이름대로 저장한다.

묶을 때는 반대로 한다. 파일 크기를 재서 오프셋을 누적하며 헤더를 쓰고 내용을 이어 붙인 뒤 두 파일에 변환을 건다.
